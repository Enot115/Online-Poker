# MathPoker

Первый этап: аккаунты игроков, регистрация и вход, отображение статуса авторизации и выход.

Второй этап: макеты лобби, покерного стола, задачника и профиля. 
 
Третий этап: схема БД, модели и бизнес-логика игрового баланса, мест за столами и наград за ежедневные задачи. Игровые фишки — внутренняя награда; реальные деньги не используются. Игровые действия и статистика в интерфейсе пока демонстрационные.

## Данные и правила

- У игрока есть целочисленный баланс игровых фишек; пополнение и списание выполняются атомарно, баланс не может быть отрицательным.
- У покерного стола заданы блайнды, бай-ин, вместимость и статус. Вход списывает бай-ин и создаёт место с соответствующим стеком; выход возвращает стек игроку.
- Ежедневная задача имеет дату, условие, правильный ответ и награду. Правильный ответ начисляет награду один раз на игрока и сохраняется в истории выполнений.
- Связи игроков, столов и выполненных задач, а также ограничения целостности хранятся в БД.

Проверить модели можно из Rails console, например: `table.join!(user)`, `seat.cash_out!` и `challenge.solve!(user:, answer:)`.


## Запуск

```sh
bundle install
bin/rails db:prepare
bin/rails server
```

Откройте http://localhost:3000. Регистрация доступна по ссылке «Создать аккаунт», для входа используйте email и пароль. Сессия хранится в зашифрованной cookie и действует до 30 дней; обновление страницы не завершает вход. Кнопка «Выйти» очищает сессию.

## Проверки

```sh
bin/rails test
```

Тесты бизнес-логики моделей находятся в `test/models/`.
