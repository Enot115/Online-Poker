# MathPoker

Первый этап: аккаунты игроков, регистрация и вход, отображение статуса авторизации и выход.

Второй этап: макеты лобби, покерного стола, задачника и профиля. 
 
Третий этап: схема БД, модели и бизнес-логика игрового баланса, мест за столами и наград за ежедневные задачи. Игровые фишки — внутренняя награда; реальные деньги не используются.

Четвёртый этап: сквозные сценарии — регистрация и вход, решение почасовой задачи с однократным начислением награды за час, посадка за стол со списанием бай-ина и выход с возвратом стека. Лобби, шапка и профиль показывают данные из БД. Ставки и раздачи в покере пока не реализованы.

## Данные и правила

- У игрока есть целочисленный баланс игровых фишек; пополнение и списание выполняются атомарно, баланс не может быть отрицательным.
- У покерного стола заданы блайнды, бай-ин, вместимость и статус. Вход списывает бай-ин и создаёт место с соответствующим стеком; выход возвращает стек игроку.
- Новая интегральная задача появляется каждый час. Правильный ответ начисляет фишки один раз на игрока за этот час и сохраняется в истории выполнений.
- Связи игроков, столов и выполненных задач, а также ограничения целостности хранятся в БД.

Проверить модели можно из Rails console, например: `table.join!(user)`, `seat.cash_out!` и `challenge.solve!(user:, answer:)`.


## Запуск

```sh
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

Откройте http://localhost:3000. Регистрация доступна по ссылке «Создать аккаунт», для входа используйте email и пароль. Сессия хранится в зашифрованной cookie до завершения браузерной сессии; обновление страницы не завершает вход. Кнопка «Выйти» очищает сессию.

## Проверки

```sh
bin/rails test
```

Тесты бизнес-логики моделей находятся в `test/models/`.
